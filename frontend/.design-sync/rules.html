Critical Design Rules — Do Not Break

Visual Rules

1
No box-shadow on any element. Ever. All depth via background contrast + borders.
2
Only font-weight 400 and 500. Never bold (600/700). Hierarchy via size and color only.
3
App background: always #F4F5F7. Never white. Never pure gray.
4
Card background: always #FFFFFF. Never tinted unless accented (celebration/unread).
5
Card corner radius: 13-16px. Never 0, never 50%.
6
All avatars are circular (border-radius: 50%). Never rectangular. Always initials.
7
Icon library: Tabler outline ONLY. No filled variants. No other icon library.
8
Icon tiles must have 1-1.5px colored border. Never flat fill without border.
9
"You" row: always blue left-stripe + #F5F9FF bg in any ranked list.
10
Serif font only for recognition quotes and wellness reflections. Never elsewhere.

Interaction Rules

11
Back labels use parent screen name, never generic "Back".
12
Bottom nav NEVER shown on detail screens. Root screens only.
13
Admin nav is completely separate from member nav.
14
Progress bar colors encode status: teal = healthy, amber = expiring, red = below threshold (admin only).
15
Min touch target: 44px primary, 34px secondary.
16
Color never conveys meaning alone — always pair with text or icon.

Color Semantic Mapping

DO: Color = meaning Blue = brand/active
Teal = success/wellness
Amber = recognition/gold
Red = urgent/error
Purple = mindset/mentions
Coral = sports/events
DON'T: Color = decoration Don't use teal "because it looks nice"
Don't use red for non-urgent items
Don't use amber outside recognition
Don't mix semantic meanings
Every color use must be intentional

Quality Bar

Target: premium blend of LinkedIn Premium (identity), Strava (gamification), Apple Fitness (progress rings), Linear (structured admin), Airbnb (event discovery). If it looks like enterprise HR software, it hasn't reached the standard.
