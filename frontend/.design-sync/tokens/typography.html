Rules

Only two weights: 400 (regular) and 500 (medium). Never use 600/700/bold.

Font: Inter / system-ui sans-serif for all UI. Serif reserved ONLY for recognition quote blocks and wellness reflections.

Uppercase ONLY for: section header labels, pill text, module eyebrow labels. Never body content.

Minimum: 9px for pills, 10px for body-facing text, 11px for readable text.
